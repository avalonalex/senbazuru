# Origami beats straightedge and compass

The Huzita-Hatori axioms enumerate the seven distinct ways a single fold can be
specified by aligning combinations of points and lines -- "fold so that point p1
lands on point p2", "fold along the line through two points", and so on.

The interesting one is axiom 6: fold so that point `p1` lands on line `l1` *and*
point `p2` lands on line `l2`, simultaneously. Solving for that fold means
solving a cubic equation.

That single fact settles two classical problems. Trisecting an arbitrary angle
and doubling the cube both reduce to cubics, and both are provably impossible
with straightedge and compass. With paper, both are ordinary constructions you
can do in a few folds.

So origami is *strictly more powerful* than Euclidean construction. Allowing
several simultaneous folds takes it further still.

## Why it matters here

Nothing immediately -- these are constructions, not renderings. But if senbazuru
grows the authoring tools in the roadmap, the axioms are the natural vocabulary
for "add a crease": not "put a line here" but "fold this point onto that one".
Each axiom also has a conventional arrow in diagram notation, so they connect
back to the drawing side.
